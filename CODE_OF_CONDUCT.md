# Code of conduct

Be respectful. Assume good intent. Criticise code, not people. No harassment,
personal attacks or discrimination of any kind, in issues, pull requests or
anywhere else connected to this project.

Maintainers may edit, remove or reject contributions and comments that break
these rules, and may block repeat offenders.

To report a problem, open a GitHub security advisory (which is private) or
contact the maintainer through their GitHub profile.
